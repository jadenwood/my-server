How to join

  1. Press Play. Steam starts your own copy of Reign of Kings.
  2. In the game's server menu, use direct connect (the Local Host field).
  3. Enter 127.0.0.1 and port 7350.

The launcher never changes game files. It only opens Steam and shows you where to connect.
