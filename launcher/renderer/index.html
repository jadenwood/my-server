        Go Public

        1Network

        Applied the next time the server starts. isPrivate only hides a server from the browser list; it is not a password.

        2Windows Firewall

        Realm adds these rules only when you press the button and accept the Windows permission prompt. Each one is limited to this server's ROK.exe and its ports. Remove rules deletes exactly these.

        3Router

        In your router's port forwarding page, send these ports to this PC (-). Realm never changes your router.

        Never forward TCP 11000 to 11003: the game's admin console listens there and has no password.

        4Check

        • Start the server, then run the checks.

        Checks from this PC cannot fully prove that strangers can reach you over UDP. The final test: a friend outside your network opens the Realm player app and sees the server online.
