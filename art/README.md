# Realm art pack

This folder holds original heraldry and brand art for the Realm of Ostreval: six engraved house sigils with banner and shield versions, the Realm logo, an icon for every Chronicle event type, key art of the Old Throne, season and renown title badges, parchment and iron textures, Discord art and a social card template. Usage rules are in [`docs/brand.md`](../docs/brand.md). To see everything, open [`index.html`](index.html) in a browser. It works straight from disk; with no network the gallery falls back to system serif fonts.

## What's here

| Path | What | How it is made |
|---|---|---|
| `sigils/<house>.svg` | House roundels, 256 × 256, in the engraved style (see `docs/brand.md`) | **Hand-drawn** (path data drawn with `tools/pen.mjs`) |
| `banners/<house>.svg`, `shields/<house>.svg` | Banner (200 × 340) and shield (240 × 280) for each house | Generated from the sigil's `<g id="charge">` |
| `logo/realm-emblem.svg` | The emblem: crown in the Old Throne | **Hand-written** |
| `logo/realm-logo-{horizontal,stacked}-{dark,light}.svg`, `logo/realm-wordmark-{dark,light}.svg`, `logo/realm-emblem-mono.svg`, `logo/realm-favicon.svg` | Lockups and small marks | Generated from the emblem and `src/wordmark.json` |
| `src/wordmark.json` | REALM / OSTREVAL as SVG path data | Outlined once from Cinzel (OFL) by `tools/wordmark.mjs` |
| `src/cinzel-bold-widths.json` | Cinzel Bold advance widths, used to wrap social-card titles | Written by `tools/wordmark.mjs` |
| `icons/*.svg` | 42 event icons on a 24px grid, one per Chronicle event type | **Hand-written** |
| `icons/event-map.json` | The icon for each Chronicle event type | **Hand-written** |
| `sprite/icons.svg` | All icons as `<symbol>`s | Generated |
| `keyart/old-throne-{1920,1200}[-title].svg` | Key art: the Old Throne above the Hearth at dusk, 1920 × 1080 and 1200 × 630, with and without the logo | Generated by `tools/sets.mjs` (seeded, so rebuilds are identical) |
| `badges/seasons/season-{1..4}.svg` | Season medals, 256 × 256 | Generated by `tools/sets.mjs` |
| `badges/titles/<title>.svg` | One badge per default RealmRenown title, 256 × 256 | Generated from `src/titles.json` and the emblems |
| `src/titles.json` | The renown titles and each one's emblem | **Hand-written**; a test checks it against `plugins/RealmRenown.cs` |
| `src/emblems/*.svg` | Title emblems on the icon grid (kingslayer, horn, axe and so on) | **Hand-written** |
| `textures/{parchment,iron}.svg` | 512px tileable textures | Generated by `tools/sets.mjs` |
| `discord/*.svg` | Server icon 512, banner 960 × 540 and invite splash 1920 × 1080 (both built on the key art) | Generated |
| `social/card-template.svg`, `social/card-example-*.svg` | 1200 × 630 link-preview card | Generated |
| `palette.json` | Every colour the pack may use | **Hand-written**, enforced by the checker |
| `png/` | PNG exports of everything above, plus `icons/contact-sheet.png` | Rendered with headless Chromium |
| `index.html` | Gallery | Generated |
| `tools/` | `build.mjs` (build, lint, export), `sets.mjs` (key art, badges, textures), `pen.mjs` (drawing helpers), tests | **Hand-written** |

Generated files say so in their `<desc>`. Edit the hand-written source, never a generated file. The next build overwrites generated files.

## Building

You need Node 18 or newer. The tools need `svgo` (optimising), `playwright` (PNG export) and `opentype.js` (only to re-outline the wordmark). None of these is committed.

```
cd art/tools && npm install          # once; or point ART_NODE_MODULES at a node_modules folder that has them
node art/tools/build.mjs all         # generate + optimise + PNGs + gallery + check
node --test art/tools/test/*.test.mjs
```

The steps can also be run one at a time: `generate`, `optimize`, `png`, `gallery` and `check`. `check --skip-png` runs the lint without a browser.

PNG export uses Playwright's Chromium. Pass `--chromium <path>` (or set `PLAYWRIGHT_CHROMIUM`) to use a browser you already have. Only the social cards contain live text. For those, the exporter loads Cinzel and EB Garamond from Google Fonts. You can instead pass `--fonts <dir>` with the `.ttf` files. Either way, the export **fails** if the fonts did not load, so a card never ships in a fallback font. Behind a proxy that the browser cannot use, download the three files first (Cinzel 600 and 700, EB Garamond 500, from the Google Fonts CSS URL in `build.mjs`) and pass `--fonts`:

```
node art/tools/build.mjs generate && node art/tools/build.mjs optimize
node art/tools/build.mjs png --fonts ~/fonts && node art/tools/build.mjs gallery && node art/tools/build.mjs check
```

To re-outline the wordmark (only if its lettering changes), download Cinzel 600 and 700 from Google Fonts, then run:

```
node art/tools/wordmark.mjs --bold Cinzel-Bold.ttf --semibold Cinzel-SemiBold.ttf
```

## What `check` enforces

- Every SVG is well-formed. The `png` step also parses each one strictly in Chromium.
- Each SVG has the SVG namespace, a `viewBox` and a `<title>`.
- No scripts, event handlers, `javascript:` URLs, embedded rasters, `foreignObject`, or external `href`/`url()`. Every file is self-contained and safe to inline.
- No live `<text>` outside `social/`. Logos, badges and numerals must render without fonts.
- Ids are unique and every `url(#…)` / `href="#…"` resolves. Sigil ids are prefixed with the house name, so sigils can share a page.
- Every hex colour in every SVG is listed in `palette.json` (brand, scene, enamel or a house's colours). Colour keywords are refused, except `white` and `black` inside a `<mask>`, where they only mean "show" and "hide".
- Icons and title emblems use `currentColor` only, on a 24 × 24 grid with a 1.75 stroke.
- House field colours equal the dye the Chronicle overlay computes for that house name. The overlay's hash in `chronicle/public/assets/common.js` is re-run to check this.
- Contrast: the documented text pairs, metal on field (3:1 or better), Discord role colours (4.5:1 or better on Discord dark), and the gold numeral on each season enamel (3:1 or better).
- `docs/brand.md` documents every brand, scene, enamel and house colour and mentions no colour outside the palette.
- Every Chronicle event type in `chronicle/server.js` has its **own** icon in `icons/event-map.json`: two types sharing an icon, a type the Chronicle does not know, or a missing icon file is an error. A type with no mapping yet is a warning, so a new type added elsewhere does not break this build.
- Every title in `src/titles.json` has an existing emblem and a badge; season badges 1 to 4 exist.
- No well-known third-party franchise names appear in the pack or the brand guide.
- File size budgets: icons and emblems under 1.5 KB, sigils under 16 KB, textures under 8 KB, badges under 24 KB, the sprite under 60 KB, key art and Discord art under 220 KB, everything else under 80 KB.
- Every expected PNG exists at the right pixel size, and `index.html` exists.
- When PNGs are exported, social-card text is measured in the browser with the real fonts. The export fails if any line runs into the sigil column.

The tests (`node --test art/tools/test/*.test.mjs`) also check the event map against `KnownTypes` in `plugins/RealmChronicle.cs`, the title list against `DefaultTitles` in `plugins/RealmRenown.cs`, that the sprite carries every icon, that sigils stay unique inside banners and shields, and that the key art is deterministic.

## Adding a house sigil

1. Add the house to `palette.json`. Its `field` is the overlay dye for its name; `check` tells you if you got it wrong.
2. Copy a sigil file and draw the charge inside `<g id="charge">` on a 200 × 200 grid, in the engraved style described in `docs/brand.md` (form, edge filter, hatching and light masks, detail lines). Prefix any ids with the house key. `tools/pen.mjs` turns a few points into tapered strokes and smooth outlines.
3. Run `node art/tools/build.mjs all`. The banner, shield, PNGs and gallery entry are created for you. The Discord art shows the six great houses only.

## Adding an event icon or a title badge

- **Event icon.** Draw `icons/<name>.svg` on the 24px grid (1.75 stroke, `currentColor`), map the new Chronicle type to it in `icons/event-map.json`, and run the build. Each type gets its own icon.
- **Title badge.** Add the title to `src/titles.json` with the same id and name as in the plugin, pick an emblem from `icons/` or draw one in `src/emblems/`, and run the build. The badge is generated.
